# Projeto: Participantes

Crie um projeto em que seja possível inserir, consultar, remover e alterar uma lista de participantes de um determinado evento. O programa deve conter um menu e funcionar conforme o exemplo abaixo:

```python
===============================
   Participantes - EVENTO ABC
===============================
1 - Cadastrar participante
2 - Listar participantes
3 - Atualizar participante
4 - Remover participante
0 - Sair
===============================
Escolha uma opção: 2
Nenhum participante cadastrado.

Escolha uma opção: 1
Digite o nome do participante: Luiz Felipe da Costa
Participante cadastrado com sucesso!

Escolha uma opção: 1
Digite o nome do produto: Marcela Luana Lima
Participante cadastrado com sucesso!

Escolha uma opção: 2
Lista de participantes inscritos:
0 - Luiz Felipe da Costa
1 - Marcela Luana Lima

Escolha uma opção: 3
Digite o índice do participante a atualizar: 1
Digite o novo nome: Marcela Lima Luana
Participante atualizado com sucesso!

Escolha uma opção: 4
Digite o índice da participante a remover: 0
Participante removido com sucesso!

Escolha uma opção: 2
Lista de produtos:
0 - Marcela Luana Lima

Escolha uma opção: 0
Saindo do sistema...
```
