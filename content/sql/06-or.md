# SQL OR

O operador `OR` combina condições no `WHERE`. Para um registro aparecer no resultado, **pelo menos uma** das condições precisa ser verdadeira.

## Sintaxe

```sql
SELECT coluna1, coluna2
FROM nome_da_tabela
WHERE condição1 OR condição2;
```

## Exemplo

```sql
-- Produtos da categoria Móveis OU com preço acima de 1000
SELECT nome, categoria, preco
FROM produtos
WHERE categoria = 'Móveis' OR preco > 1000;
```

| nome     | categoria   | preco |
|----------|-------------|-------|
| Notebook | Eletrônicos | 3500  |
| Mesa     | Móveis      | 850   |
| Cadeira  | Móveis      | 420   |

O Notebook aparece porque seu preço é maior que 1000. Mesa e Cadeira aparecem porque são da categoria Móveis.

## OR vs IN

Quando você quer filtrar vários valores da **mesma coluna**, o `IN` é mais limpo que vários `OR`:

```sql
-- Com OR (funciona, mas fica repetitivo)
WHERE status = 'pendente' OR status = 'cancelado' OR status = 'devolvido'

-- Com IN (muito mais legível)
WHERE status IN ('pendente', 'cancelado', 'devolvido')
```

## AND e OR juntos

Use parênteses para deixar a precedência explícita:

```sql
-- Produtos caros OU (da categoria Móveis com bastante estoque)
SELECT nome, categoria, preco, estoque
FROM produtos
WHERE preco > 2000 OR (categoria = 'Móveis' AND estoque > 25);
```
