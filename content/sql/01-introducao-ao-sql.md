# O que é SQL?

SQL (Structured Query Language) é a linguagem padrão para interagir com **bancos de dados relacionais**. Com ela você consegue criar tabelas, inserir dados, fazer buscas, atualizar e remover registros.

A sigla pode ser pronunciada "esse-quê-éle" ou "sequel". As duas formas são amplamente aceitas.

## Para que serve o SQL?

Com SQL você consegue fazer praticamente tudo o que envolve dados estruturados:

- **Consultar dados** — buscar informações específicas em tabelas com milhões de registros;
- **Inserir dados** — adicionar novos registros a uma tabela;
- **Atualizar dados** — modificar registros existentes;
- **Deletar dados** — remover registros de forma controlada;
- **Criar estruturas** — definir tabelas, índices e relacionamentos.

## Quais bancos usam SQL?

O SQL é uma linguagem padrão e quase todos os bancos de dados relacionais o adotam. Os mais populares:

- **PostgreSQL** — open source, robusto, muito usado em produção;
- **MySQL / MariaDB** — amplamente usado em aplicações web;
- **SQLite** — leve, sem servidor, ideal para desenvolvimento local;
- **SQL Server** — banco da Microsoft, comum em ambientes corporativos;
- **Oracle** — presente em grandes empresas e sistemas legados.

A sintaxe pode variar um pouco entre eles, mas os conceitos são os mesmos. Neste curso, os exemplos são compatíveis com **MySQL e PostgreSQL**.

## Por que aprender SQL?

Porque praticamente toda aplicação que persiste dados usa um banco relacional por baixo dos panos. Analistas de dados, desenvolvedores, cientistas de dados, gestores, todo mundo acaba chegando no SQL em algum momento.

> A boa notícia: a sintaxe é muito próxima do inglês, o que torna o aprendizado bastante intuitivo. Você vai ver!
