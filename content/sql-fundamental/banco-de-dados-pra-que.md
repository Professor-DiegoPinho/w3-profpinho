# Compilado(s)

Os bancos de dados surgiram da necessidade de organizarmos os dados digitais de forma estruturada, prática e escalável. Existem diferentes tipos de bancos de dados, o que vamos estudar é chamado de **banco de dados relacionais**. Eles tem esse nome por conta da sua estrutura que permite relacionar diferentes dados de forma lógica.

Todo banco de dados relacional é composto por **tabelas**. Cada tabela representa um conjunto de dados do universo que você deseja modelar. Por exemplo: alunos, clientes, entregas, pagamentos, etc.

Assim como uma planilha, cada tabela é formada por **linhas** (rows) e **colunas** (columns).
    
# Exercícios

## Exercício 1: Banco de dados pra quê?

Explique com suas palavras para que servem os bancos de dados e qual o problema que eles resolvem.

{% toggle "Ver solução" %}

Os bancos de dados servem para organizar, armazenar e gerenciar grandes quantidades de dados de forma estruturada e eficiente. Eles resolvem o problema de como lidar com informações complexas e inter-relacionadas, permitindo que os usuários acessem, manipulem e analisem os dados de maneira rápida e fácil. Sem bancos de dados, seria difícil manter a integridade dos dados, garantir a segurança e realizar consultas eficientes em grandes volumes de informações.

Além disso, os bancos de dados também fazem com que a memória do computador seja utilizada de forma mais eficiente, já que eles permitem armazenar os dados em um formato otimizado e acessá-los de maneira rápida, sem precisar carregar tudo na memória ao mesmo tempo. Isso é especialmente importante quando lidamos com grandes volumes de dados, como em empresas, redes sociais, e-commerce, etc.
