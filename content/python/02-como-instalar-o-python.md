# Verificar instalação

Abra o terminal e execute:

```bash
python --version
```

Se não funcionar, tente:

```bash
python3 --version
```

Se aparecer a versão, ótimo! Se não, siga as instruções abaixo para instalar.

# Windows

1. Vá para [python.org/downloads](https://www.python.org/downloads/)
2. Baixe e execute o instalador
3. **Importante**: marque "Add Python to PATH"
4. Clique em "Install Now"

# macOS

**Usando Homebrew**:

```bash
brew install python
```

Ou baixe direto do [python.org](https://www.python.org/downloads/)

# Linux

Geralmente já vem instalado:

```bash
python3 --version
```

Se não tiver:

```bash
sudo apt install python3
```

# Validar instalação

Após instalar, verifique:

```bash
python --version  # ou python3
```
