# O que é Python?

Python é uma linguagem de programação simples, poderosa e muito popular. É perfeita para iniciantes porque a sintaxe é clara e parecida com o português.

## Para que serve?

- **Web**: criar servidores e APIs com Django, Flask, FastAPI;
- **Automação**: scripts para tarefas repetitivas, web scraping;
- **Dados e IA**: análise de dados, machine learning;
- **Ciência**: pesquisa, simulações, modelagem;
- **Scripts**: qualquer automação que você pensar.

## Por que aprender Python?

- Sintaxe simples e legível;
- Menos código comparado a outras linguagens;
- Funciona em Windows, Mac, Linux;
- Comunidade grande e muitas bibliotecas;
- Ideal para começar na programação.
