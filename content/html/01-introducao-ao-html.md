# O que é HTML?

HTML (**HyperText Markup Language**) é a linguagem de marcação usada para criar a **estrutura** de uma página web.

Com HTML você define o que cada parte da página é: um título, um parágrafo, uma imagem, um link, uma lista e assim por diante.

Ele não cuida do visual bonito da página e nem da interatividade. 

De forma simples:

- **HTML** estrutura o conteúdo;
- **CSS** estiliza;
- **JavaScript** adiciona comportamento.

## Exemplo simples

Um arquivo HTML bem básico pode ser assim:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Minha primeira página</title>
  </head>
  <body>
    <h1>Olá, mundo!</h1>
    <p>Esta é a minha primeira página em HTML.</p>
  </body>
</html>
```

## Entendendo o exemplo

Nesse código:

- `<!DOCTYPE html>` informa que o documento usa HTML5;
- `<html>` representa o documento inteiro;
- `<head>` guarda informações sobre a página;
- `<title>` define o nome que aparece na aba do navegador;
- `<body>` contém o conteúdo visível;
- `<h1>` é um título principal;
- `<p>` é um parágrafo.

## HTML na prática

No dia a dia, HTML é usado para montar a base de páginas como:

- páginas de site;
- blogs;
- formulários;
- páginas de login;
- áreas administrativas.

Mesmo em projetos com frameworks modernos, o HTML continua ali por baixo dos panos. Saber o básico de HTML é essencial para entender como a web funciona e para criar páginas que sejam acessíveis e bem estruturadas.
