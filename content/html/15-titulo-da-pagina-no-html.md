# Nomeando a página do jeito certo

O título da página é o texto que aparece na aba do navegador.

Ele também costuma ser usado em favoritos e ajuda a identificar o conteúdo quando a pessoa está com várias abas abertas.

## Exemplo básico

```html
<head>
  <title>Cadastro de Clientes</title>
</head>
```

## O que a tag `<title>` faz?

Ela define o nome da página para o navegador.

Esse conteúdo não aparece no corpo da página, mas continua sendo muito importante.

## Exemplo completo

```html
<!DOCTYPE html>
<html>
  <head>
<title>Loja Virtual - Produtos</title>
  </head>
  <body>
<h1>Produtos em destaque</h1>
  </body>
</html>
```

## Uma dica simples

Evite títulos vagos como:

- `Página inicial`
- `Documento`
- `Teste`

Eles funcionam? Funcionam. Mas ajudam menos do que deveriam.

Um bom título explica rapidamente o que aquela página é.
