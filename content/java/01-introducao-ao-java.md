# O que é Java?

Java é uma linguagem de programação orientada a objetos, criada pela Sun Microsystems (hoje parte da Oracle) e lançada em 1995. É uma das linguagens mais usadas no mundo, especialmente em sistemas corporativos, aplicativos Android e plataformas de back-end de grande escala.

## Para que ele é usado?

- Aplicativos Android, onde foi por muitos anos a linguagem oficial;
- Sistemas corporativos e bancários, com frameworks como Spring;
- APIs e aplicações de back-end;
- Sistemas embarcados e dispositivos com recursos limitados;
- Big data, em ferramentas como Hadoop e Spark, que são construídas em Java.

## Por que usar Java?

- Roda em qualquer sistema operacional através da JVM (Java Virtual Machine), seguindo o princípio "escreva uma vez, execute em qualquer lugar";
- Tipagem estática, o que ajuda a identificar erros antes mesmo de executar o programa;
- Orientado a objetos desde sua base, o que organiza bem projetos grandes;
- Comunidade enorme, com bibliotecas para praticamente qualquer necessidade;
- Amplamente usado no mercado de trabalho, principalmente em empresas de grande porte.

> Curiosidade: apesar do nome parecido, Java não tem relação direta com JavaScript. São linguagens diferentes, criadas por empresas diferentes, com propósitos diferentes.
